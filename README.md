# COVID-19 Statistics System

![Java](https://img.shields.io/badge/java-17%2B-blue)
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-2.7%2B-brightgreen)
![GitHub last commit](https://img.shields.io/github/last-commit/DanielChitay/Covid19StatsSegundoParcial)

Sistema de análisis y visualización de estadísticas COVID-19 con:
- Carga automática de datos desde API pública
- Procesamiento de árboles binarios para análisis de rutas de propagación
- Generación de reportes

## 🚀 Características principales

- **Carga automática de datos** mediante scheduled task
- **API REST** para consulta de estadísticas
- **Análisis de árboles binarios** para patrones de propagación
- **Generación de reportes** en formato TXT
- **Registro de ejecuciones** en base de datos

## 🛠️ Tecnologías utilizadas

- Java 17+
- Spring Boot 2.7+
- Spring Data JPA
- H2 Database (para desarrollo)
- Log4j2 para logging
- Maven
